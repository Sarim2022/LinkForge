LinkForge is an Android application that helps users track, manage, and understand their personal finances in a smarter way. The app allows users to monitor wallets, record transactions, analyze spending, and interact with an AI assistant that can answer questions about their financial activity.

Security

Sensitive keys like the Gemini API key are stored in local.properties and accessed through BuildConfig to prevent exposing them in the codebase.
