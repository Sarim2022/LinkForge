🛠️ LinkForge: Expense Manager
LinkForge is a modern, high-performance Android expense tracker built with Jetpack Compose. It is designed to help users "forge" a better financial future by linking daily spending habits to long-term goals.

🚀 Features
Smart Dashboard: Real-time overview of your wallets and total balance.

Transaction Tracking: Categorize income and expenses with ease.

Dynamic UI: Fully responsive layout that adapts to various screen sizes using custom scaling logic.

Google Authentication: Secure and professional one-tap sign-in.

Modern Transitions: Smooth splash-to-auth animations for a premium user experience.
